## 🚀 Live Demo & Local Preview

### 1. View Portfolio
Open `index.html` in any web browser. Features:
- **Executive Dark & Light Mode** with local storage memory.
- **Quantified Proof Points**: 35+ B2B Solar Deals, 150+ Compliance Articles, 3.55 CGPA, 4x Google Certifications.
- **Interactive Role Filter**: Instant categorization for B2B Commercial, SEO & Growth, and Leadership.
- **Direct Conversion Channels**: One-click email copy with toast feedback and direct WhatsApp messaging.

### 2. Export 1-Page Resume to PDF
1. Open `resume_template.html` in Google Chrome or Microsoft Edge.
2. Press **Ctrl + P** (or click the "Print to PDF" button at the top).
3. Set destination to **Save as PDF**, paper size to **A4**, and ensure **Background graphics** is checked.
4. Save your polished, zero-overflow single-page resume!
